\section{Limitations and future work}
\label{sec:limitations}

\begin{itemize}
  \item \textbf{Bounded knowledge.} The product answers from curated banks and
        labeled peak spans; open-world chat is out of scope by design.
  \item \textbf{No true-continue yet.} Mini-AGI-\emph{inspired} generate remains
        deferred; claims must not inflate HOLD/DEFER into unlock.
  \item \textbf{Forever pack is finite.} Closing BA-FOREVER does not prove
        unbounded intent generalization; continuous outside-pack probes remain
        mandatory.
  \item \textbf{Single-lab compute.} Metrics come from one repository and CPU
        serve path; independent replication is encouraged via npm runners and
        frozen JSON boards.
  \item \textbf{Wave inflation risk.} Letter clones (CTX/SMART/FAST/APP) can
        republish metrics without scientific novelty; future waves require a
        named hole on the anti-FP scoreboard or a real generative method.
\end{itemize}

\paragraph{Future work (real gain only).}
(1)~General intent/ops gates beyond class patches;
(2)~one real generative method (distill continue, hybrid rejector, or named CAPCHECK)
with true-continue PROMOTE;
(3)~publishable external replication pack;
(4)~prefer honest negative papers over vanity wave letters.
